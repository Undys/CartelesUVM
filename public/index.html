Código Numérico del Cartel (Manual o Al Azar por Nivel)

El código lleva únicamente números y empieza según el nivel: 1 para Nivel 1 (ej. 101), 2 para Nivel 2 (ej. 201) y 3 para Nivel 3 (ej. 301). Puedes escribirlo manualmente, generarlo con el botón o dejarlo vacío para asignarlo al azar.
